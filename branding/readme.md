# Branding Logo Folder

Taruh logo aplikasi di folder ini agar otomatis dipakai di UI dan favicon.

Untuk kebutuhan tema:

1. Tema default: `KitaAtur2.svg` (atau `.png/.jpg/.jpeg`)
2. Tema invert: `KitaAtur.svg` (atau `.png/.jpg/.jpeg`)

Fallback yang tetap didukung:

1. `app-logo.svg`
2. `app-logo.png`
3. `app-logo.jpg`
4. `app-logo.jpeg`
5. `/logo.png`

Jika tidak ada file di atas, komponen logo akan fallback ke monogram.
